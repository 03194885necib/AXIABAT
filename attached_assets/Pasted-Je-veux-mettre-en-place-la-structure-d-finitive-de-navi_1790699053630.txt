==================================================
1. CONNEXION
==================================================

Conserver la page Login actuelle.

Utiliser Firebase Authentication déjà présent dans AXIABAT.

Après connexion réussie :

/login
   ↓
/home

NE PAS envoyer directement l'utilisateur vers /dashboard.

Conserver ProtectedRoute et toutes les protections existantes.

Après déconnexion :

/home
   ↓
/login


==================================================
2. HOME — PAGE D'ACCUEIL AXIABAT
==================================================

Créer une page indépendante :

/home

Cette page est la véritable page d'accueil d'AXIABAT.

Créer si nécessaire :

src/Pages/Home/Home.js
src/Pages/Home/Home.css

La page doit présenter AXIABAT avant que l'utilisateur accède aux différents modules.

CONTENU PRINCIPAL :

AXIABAT

"Plateforme intégrée de gestion des projets BTP"

Puis un texte de présentation :

"AXIABAT est une plateforme digitale destinée à centraliser,
piloter et suivre les projets BTP, les travaux, les délais,
les coûts, les indicateurs et le reporting."

Afficher également une phrase :

"Pilotez vos projets BTP depuis une plateforme unique."

6. HOME NE DOIT PAS ÊTRE LE DASHBOARD
==================================================

IMPORTANT :

Home et Dashboard sont deux pages différentes.

HOME :

Objectif :
- présentation d'AXIABAT ;
- accueil ;
- orientation ;
- accès aux fonctionnalités.

DASHBOARD :

Objectif :
- indicateurs ;
- statistiques ;
- projets actifs ;
- avancement ;
- arrêts ;
- rapports ;
- données de pilotage.

Le Dashboard actuel doit rester fonctionnel.

Ne pas déplacer ses fonctionnalités dans Home.

Ne pas supprimer ses composants.
