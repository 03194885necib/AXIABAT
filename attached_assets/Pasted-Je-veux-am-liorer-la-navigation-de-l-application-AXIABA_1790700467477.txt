Je veux améliorer la navigation de l'application AXIABAT.

OBJECTIF
Ajouter un bouton permanent :

← Retour à l'accueil

en haut de chaque module accessible depuis la page /home.

PROBLÈME ACTUEL
Après l'entrée dans certains modules, notamment :
- Gestion des projets
- Journal de chantier
- Gestion des délais
- Suivi budgétaire
- Tableau de bord
- Reporting
- Base de données

certains modules n'affichent pas correctement le header/menu principal ou ne permettent pas facilement de revenir à la page d'accueil.

SOLUTION DEMANDÉE
Créer un composant de navigation réutilisable, par exemple :

src/Components/shared/BackToHome.js

ou utiliser un composant partagé existant si une solution équivalente existe déjà.

Le composant doit afficher :

← Retour à l'accueil

et naviguer vers :

/home

COMPORTEMENT
1. Le bouton doit être placé EN HAUT de la page/module.
2. Il doit être visible immédiatement après l'ouverture du module.
3. Il doit fonctionner sur PC, tablette et mobile.
4. Il doit être suffisamment visible et professionnel.
5. Utiliser le système de navigation React Router déjà présent dans le projet.
6. Ne pas utiliser window.location.reload().
7. Ne pas créer une nouvelle page Home.
8. Ne pas créer une nouvelle collection Firebase.
9. Ne pas modifier la logique métier existante des modules.
10. Ne pas supprimer les menus ou fonctionnalités existants.

MODULES À VÉRIFIER

Ajouter ce bouton dans les pages principales correspondant aux modules :

1. Gestion des projets
2. Journal de chantier
3. Gestion des délais
4. Suivi budgétaire
5. Tableau de bord
6. Reporting
7. Base de données

IMPORTANT
Le bouton doit être présent même si le module possède déjà son propre header.

S'il existe déjà plusieurs composants Header/Menu/Navigation dans le projet, ne pas les remplacer inutilement.
Créer plutôt un composant partagé réutilisable et l'intégrer proprement.

DESIGN
Le bouton doit être placé par exemple :

------------------------------------------------
← Retour à l'accueil
------------------------------------------------
Titre du module
Contenu du module

Utiliser le style visuel professionnel AXIABAT déjà présent dans l'application.

Prévoir :
- icône flèche retour
- texte "Retour à l'accueil"
- effet hover
- bonne lisibilité
- marge/padding correct
- responsive mobile
