REGLES D'IMPORTATION
====================

1. Lire le fichier Excel avec une bibliothèque compatible XLSX.

2. Identifier automatiquement les rubriques.

3. Conserver la rubrique courante comme catégorie de l'article.

Exemple :

RESEAU D’EAUX USEES
    ↓
CONDUITE GRAVITAIRE PVC Ø 315
    unité = ml

doit devenir quelque chose comme :

category = "RESEAU D’EAUX USEES"
designation = "CONDUITE GRAVITAIRE PVC Ø 315"
unit = "ml"

4. Nettoyer les espaces inutiles.

5. Conserver les accents français :
   é, è, ê, à, ç, œ, etc.

6. Conserver les caractères techniques :
   Ø
   ≤
   ≥
   °
   /
   -
   +
   parenthèses

7. Normaliser uniquement les unités lorsque nécessaire.

Par exemple :
   M3 → m3
   M² → m2
   M2 → m2
   ml → ml
   ML → ml
   U → U
   Ens → Ens
   T → T

Ne pas modifier la désignation technique elle-même.

8. Les lignes contenant uniquement une rubrique et aucune unité/article doivent être ignorées comme articles.

9. Les lignes vides doivent être ignorées.

10. Les doublons doivent être détectés.

UTILISATION DES CODES ARTICLES
==============================
Avant de créer un nouveau champ "code", analyse le modèle de données existant.

Si AXIABAT possède déjà un champ code article :
- respecter ce champ ;
- ne pas casser le système existant.

Si un code est obligatoire mais qu'aucun code n'est fourni dans le fichier Excel :
- générer un identifiant stable du type ART-001, ART-002, ART-003...
- ne pas utiliser le numéro de ligne Excel comme code si cela peut provoquer des conflits.

Si le système possède déjà une codification BTP, utiliser la codification existante.

IMPORT IDEMPOTENT
=================
L'import doit être idempotent.

Cela signifie que si je lance deux fois l'import du fichier Excel :

- les mêmes articles ne doivent pas être insérés deux fois ;
- les articles existants doivent être détectés ;
- seul le premier import doit créer les nouveaux articles.

Utiliser comme clé de détection, selon le schéma existant :

designation + unite + categorie

ou la clé unique déjà définie dans la base.
